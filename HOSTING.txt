УСТАНОВКА НА BOTHOST.RU

1. Откройте https://bothost.ru/create-bot.php и создайте Discord-бота.
2. Выберите Python / discord.py (если есть выбор библиотеки).
3. Загрузите ZIP-архив проекта через загрузку из архива (или подключите Git-репозиторий).
4. Главный файл (точка входа): bot.py
5. В настройках переменных окружения добавьте:
   DISCORD_BOT_TOKEN = токен вашего Discord-бота
   GUILD_ID = 1533075462383730838
   REVIEW_CHANNEL_ID = 1533076154783764663
   TERMINATED_ROLE_ID = 1533075835097976893
   REVIEWER_ROLE_IDS = 1533075692785504327
   DB_PATH = /app/data/terminations.sqlite3
6. Если панель Bothost предлагает постоянное хранилище/volume, подключите его и используйте путь /app/data.
7. Нажмите создать/развернуть и проверьте логи: должно появиться сообщение о запуске бота.

Код понимает оба имени токена: DISCORD_BOT_TOKEN (Bothost) и DISCORD_TOKEN.
Токен вводится только в секретные переменные окружения Bothost. Не отправляйте его в чат и не добавляйте в архив/Git.

Discord Developer Portal:
- Включите Server Members Intent.
- Пригласите бота с scopes bot и applications.commands.
- Права: Manage Roles, Manage Nicknames, View Channels, Send Messages, Embed Links, Read Message History.
- Перетащите роль бота выше ролей сотрудников и роли «Уволен».

Команды после запуска:
- /setup_resignation

ПРИМЕЧАНИЕ:
Bothost принимает ZIP-архивы или Git-репозитории. Уточняйте доступность загрузки ZIP в интерфейсе своего тарифа.
Для сохранения SQLite между пересозданиями контейнера используйте постоянное хранилище по инструкции Bothost.


Команда настройки панели: /setup_resignation
Других slash-команд нет: подача, одобрение и отклонение заявлений выполняются через кнопки и формы панели.

БОТ ДЛЯ ЗАЯВЛЕНИЙ НА УВОЛЬНЕНИЕ — ГИБДД | RMRP «Тверской»

Что умеет:
1. Команда /панель-увольнения публикует панель с кнопкой подачи заявления.
2. Сотрудник нажимает кнопку и заполняет никнейм, Static ID, звание и причину.
3. Заявление отправляется в настроенный канал руководства.
4. Руководство нажимает Одобрить или Отклонить.
5. При одобрении бот снимает роли сотрудника, которые находятся ниже роли бота,
   выдаёт роль «Уволен» и меняет серверный ник на [УВОЛЕН] Никнейм.
6. Заявления и статусы хранятся в SQLite; кнопки рассмотрения работают после перезапуска.
7. Команда /увольнение-статистика показывает последние 10 заявлений.

ВАЖНО:
- Discord не позволит боту снимать роли, которые стоят выше или на одном уровне
  с его высшей ролью. Переместите роль бота выше всех ролей сотрудников.
- Для полного выполнения нужны разрешения Manage Roles и Manage Nicknames.
- @everyone бот не снимает.
- Если у сотрудника есть роли выше роли бота, Discord не даст их снять.
- Никнейм Discord ограничен 32 символами; длинный ник может быть обрезан.
- Не публикуйте токен бота и не отправляйте его посторонним.

УСТАНОВКА:
1. Установите Python 3.11 или новее.
2. В Discord Developer Portal создайте приложение и добавьте Bot.
3. Включите Server Members Intent в разделе Bot → Privileged Gateway Intents.
4. Сгенерируйте ссылку OAuth2 с scopes: bot и applications.commands.
5. Выдайте боту права:
   View Channels, Send Messages, Embed Links, Read Message History,
   Manage Roles, Manage Nicknames.
6. Добавьте бота на сервер.
7. Скопируйте .env.example в файл .env.
8. Заполните .env: токен, ID сервера, канала заявлений, роли «Уволен»,
   роли руководства.
9. Переместите роль бота выше ролей, которые он должен снимать.
10. Запустите start.bat (Windows).

КАК ПОЛУЧИТЬ ID:
В Discord включите Настройки → Дополнительно → Режим разработчика.
Затем нажмите правой кнопкой на сервер/канал/роль → Копировать ID.

КОМАНДЫ:
 /setup_resignation — опубликовать панель (требуются права администратора).
Все дальнейшие действия выполняются кнопками и формами внутри панели.

Если бот не видит slash-команды сразу, подождите несколько минут и перезапустите его.

ОСТАЛОСЬ:
- Скопировать .env.example в .env.
- Вставить токен бота в DISCORD_TOKEN.
- Пригласить бота на сервер и запустить start.bat.


ИСПРАВЛЕНИЕ ВИДИМОСТИ КОМАНДЫ:
Команда /setup_resignation теперь доступна участникам с ролью старшего состава
(или администраторам). После старта бот синхронизирует команду именно с сервером
из GUILD_ID и выводит список синхронизированных команд в консоль.
